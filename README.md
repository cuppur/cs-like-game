# cs-like-game — 类CS拆弹射击游戏

> Fable5.1大人根据一句提示词28分钟做出的类CS游戏

单文件 HTML 3D 射击游戏（Three.js + Web Audio），直接双击打开 `index.html` 即可游玩，或部署到 GitHub Pages。

## 🎮 游戏内容概览

**核心玩法 — 5v5 拆弹模式**

* 选择 CT（反恐精英） 或 T（恐怖分子） 阵营，与 AI 队友并肩作战，先赢 8 回合者获胜
* T 方需在 A/B 点安放 C4（按住 E 3秒），CT 方需守点或拆弹（10秒 / 拆弹器 5秒）
* 炸弹掉落可拾取、40 秒倒计时越来越急促的蜂鸣、爆炸范围伤害
* 完整回合流程：冻结时间 → 对局 → 结算横幅 → 下一回合，含时间耗尽、全灭等各种胜负判定

**武器与经济系统**

* 9 种武器：军刀、Glock、USP、沙漠之鹰、MP5、AK-47、M4A1、AWP（可开镜）、Nova 霰弹枪（8 颗弹丸）
* 高爆手雷（物理弹跳 + 范围伤害）、闪光弹（根据朝向致盲玩家和 AI）
* 防弹衣/头盔/拆弹器，按 B 打开购买菜单，击杀奖励、回合胜负奖金、连败补助均按 CS 规则
* 后坐力上跳、移动/跳跃/蹲下影响散布、动态准星、爆头 4 倍伤害、腿部减伤、护甲减伤

**AI 机器人**

* A* 寻路 + 路径平滑，视野锥 + 视线遮挡检测，听到枪声/被击中会转向寻敌
* 状态机：目标（去炸弹点/守点/安放/拆弹/捡炸弹）→ 追猎最后目击位置 → 交火（扫射、拉扯走位、换弹）
* 三档难度影响命中率和反应时间，随回合数升级装备（手枪局 → 冲锋枪 → 步枪/AWP）

**呈现与反馈**

* Three.js 3D 场景：程序生成的沙地/砖墙/木箱/沙袋纹理、实时阴影、雾效、炸弹点地面标识
* 第一人称武器模型（每把枪独立造型）、换弹/切枪/挥刀动画、枪口火光、曳光弹、弹孔、火花与血液粒子
* Web Audio 合成音效：各类枪声、脚步（带空间定位与声像）、命中/爆头提示、炸弹蜂鸣、爆炸、胜负音乐
* HUD：小地图（显示队友与被发现的敌人）、击杀信息、受击方向指示、红色受伤晕影、AWP 瞄准镜、计分板（Tab）、观战阵亡后可切换队友视角
* 主菜单（阵营/难度/灵敏度）、暂停菜单、比赛结算与 MVP 统计

**操作：** WASD 移动 · Shift 静步 · C/Ctrl 蹲 · 空格跳 · 左键开火 · 右键开镜 · R 换弹 · 1-4/滚轮/Q 切枪 · B 购买 · E 安放/拆弹 · Tab 计分板 · Esc 暂停
